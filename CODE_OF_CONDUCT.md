# Code of Conduct

This project adopts the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, constructive, and welcoming. Harassment or demeaning
behaviour is not tolerated. Discussion should stay focused on the science and
the software.

To report unacceptable behaviour, contact **research@kubanski.pro**. Reports
will be handled confidentially.
