# Security Policy

`rlds-paired` is a scientific computation library (NumPy/SciPy ODE integration
and plotting). It performs no network access, no authentication, and does not
parse untrusted input, so its security attack surface is minimal.

If you nonetheless discover a security-relevant issue (for example in a
dependency, or a way the package could be misused in an automated pipeline),
please report it privately to **research@kubanski.pro** rather than opening a
public issue.

Supported version: the latest released `1.x` line.
